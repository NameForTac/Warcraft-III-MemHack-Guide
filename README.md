# 魔兽争霸 III MemHack 入门导读

这份中文导读面向想了解 Warcraft III 旧版地图扩展实践的新手。它从 JASS 基础和源码结构讲起，逐步解释 MemHackAPI 的关键调用链，并介绍如何从头规划同类扩展、如何在既有项目中设计新 API。

## 阅读指南

- [《入门指南》](入门指南.md)：包含术语解释、关键源码逐行讲解、构建思路和新增 API 的检查步骤。
- [《源码结构与调用链》](源码结构与调用链.md)：按模块说明依赖关系，并逐条拆解启动、内存读写、native 调用、handle 转对象、Unit/Effect/Frame API、hook 与恢复链路。
- [《极小案例：创建并控制一个特效》](示例/01-特效控制/README.md)：从地图脚本开始，创建一个特效、调整透明度和缩放，并在三秒后销毁；附逐段源码讲解和调用链。
- [《从零设计自己的最小 MH》](示例/02-自己的最小MH/README.md)：不依赖 MemHackAPI，按 1.27a 单版本、单 API 拆解自己的最小实现应该有哪些层，以及如何逐步验证。

## 学习范围

MemHackAPI 面向特定旧版 Warcraft III 环境。本仓库的极小案例按 **Warcraft III 1.27a** 作为学习目标；上游 README 推荐 1.26a，并说明不支持 Reforged。上游源码也包含 1.27a 的版本分支，但这不等于每个 API 都已在你的 1.27a 构建上验证。文中的地址、偏移、调用约定和内部对象布局都依赖具体游戏版本，适合历史研究与静态阅读，不能直接套用到其他版本。

本文旨在帮助新人认识 Warcraft III 地图开发历史中的一部分工作，不涵盖地图制作的全部方法。涉及进程内存的内容仅用于理解旧项目；任何实践都应限于自己拥有、离线且可恢复的测试环境。

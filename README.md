# 魔兽争霸 III MemHack 入门导读

这份中文导读面向想了解 Warcraft III 旧版地图扩展实践的新手。它从 JASS 基础和源码结构讲起，逐步解释 MemHackAPI 的关键调用链，并介绍如何从头规划同类扩展、如何在既有项目中设计新 API。

## 阅读指南

- [《入门指南》](入门指南.md)：包含术语解释、关键源码逐行讲解、构建思路和新增 API 的检查步骤。

本文中关于 MemHack 的项目事实、源码结构和示例，参考自 **UnryzeC** 编写的 [MemHackAPI](https://github.com/UnryzeC/MemHackAPI)。源码示例以该项目为学习对象；请查看上游仓库获取完整源码、版本说明及作者后续更新。

本仓库是独立编写的中文学习导读，不是 MemHackAPI 的官方文档，也不代表原作者背书。上游仓库目前未声明开源许可证；原项目源码及其相关权利仍归原作者及相应权利人。本导读的发布不额外授予复制、修改或再发布上游源码的许可。

## 学习范围

MemHackAPI 面向特定旧版 Warcraft III 环境。上游 README 推荐 1.26a，并说明不支持 Reforged。文中的地址、偏移、调用约定和内部对象布局都依赖具体游戏版本，适合历史研究与静态阅读，不能直接套用到其他版本。

本文旨在帮助新人认识 Warcraft III 地图开发历史中的一部分工作，不涵盖地图制作的全部方法。涉及进程内存的内容仅用于理解旧项目；任何实践都应限于自己拥有、离线且可恢复的测试环境。
